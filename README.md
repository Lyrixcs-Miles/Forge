# Forge

> A personal software engineering workspace built for learning, building, documenting, and automating.

---

## Overview

Forge is my long-term development environment.

It is designed to be independent of any single AI model, editor, operating system, or framework.

Claude, ChatGPT, Gemini, Codex, local LLMs, and future AI tools are collaborators—not dependencies.

Forge is useful even without AI.

---

## Goals

- Build software professionally
- Learn continuously
- Automate repetitive work
- Maintain excellent documentation
- Create reusable templates
- Build a long-term personal knowledge base
- Develop portfolio-quality projects

---

## Core Principles

### Simplicity

Everything has a purpose.

If something doesn't provide value, it doesn't belong.

---

### Documentation First

Document why something exists.

Future Me should never have to guess.

---

### Automation

If a task is repeated often, automate it.

---

### Consistency

Every project should follow the same standards.

---

### Tool Independence

Forge should work regardless of which AI, IDE, or framework is used.

---

## Workspace Structure

projects/
: Active software projects.

knowledge/
: Technical notes and references.

memory/
: Long-term notes, ideas, and decisions.

prompts/
: Reusable prompts for AI tools.

templates/
: Starter templates for new projects.

scripts/
: Automation and utility scripts.

tools/
: Custom development tools.

configs/
: Configuration files.

docs/
: Documentation.

agents/
: AI assistant configurations.

assets/
: Images and shared media.

scratch/
: Temporary experiments.

---

## Philosophy

Forge is not just a folder.

It is an engineering workshop.

Every project, document, script, and tool should make future work easier than it is today.
